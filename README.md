# Quick Contract

A modern contract management dashboard built with React, TypeScript, and Chakra UI.

## Features

- **Contract Management Dashboard**: Comprehensive overview of contract activities, earnings, and progress
- **Contract Builder**: Create and manage contracts with an intuitive interface
- **Contract Marketplace**: Browse and bid on available contracts
- **User Authentication**: Secure sign-in system
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Dark/Light Mode**: Toggle between color themes
- **RTL Support**: Right-to-left language support

## Technology Stack

- **Frontend**: React 18 with TypeScript
- **UI Framework**: Chakra UI v2
- **Icons**: React Icons
- **Routing**: React Router DOM
- **Charts**: ApexCharts
- **Build Tool**: Create React App

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start development server**:
   ```bash
   npm start
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

## Project Structure

```
src/
├── components/          # Reusable UI components
├── layouts/            # Page layout components
├── views/              # Page components
├── theme/              # Chakra UI theme configuration
├── utils/              # Utility functions
└── assets/             # Images and static files
```

## Default Route

The application now defaults to the login screen (`/auth/sign-in`) as the first screen users see.
